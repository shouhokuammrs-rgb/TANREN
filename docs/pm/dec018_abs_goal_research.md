# DEC-018 調査ノート: 腹ゴールの根拠(2026-08-02・PM)

## 調査結果
- 自重系レップ標準は存在(Strength Level: クランチ65万件超・男性Int平均55回、シットアップ系も同様)。ただしこれらは**1セット最大回数**の物差しで、TANRENの「3セット×レンジ上限」とは非互換
- **ダンベル抱えクランチのkg標準は存在しない**。ケーブルクランチ(男Int 1RM≈77kg)・マシンクランチの標準はあるが、滑車・レバー機構込みの数値でダンベルへの流用は力学的に不可
- 結論: 腹に「体重×係数」は作れない(DEC-013の判断を再確認)

## 採用設計(DEC-018)
- **段位=ラダー種目クリア型**(新規の数値基準を発明しない): 引き締め=クランチ卒業 / しっかり=レッグレイズ卒業 / がっつり=ダンベルクランチ(2.5kg〜)上限完遂。物差しはDEC-017ラダー+実装済みレップレンジ上限のみ
- 到達→鏡チェック→維持/継続は他部位と共通ループに合流
- **見え方軸(補助)**: body_statsに体脂肪率(任意入力・体組成計値)。腹詳細で「厚み(段位)×薄さ(体脂肪率トレンド)」の2軸表示。目安ライン(うっすら≈15%/割れ目≈12%/バキバキ≈10%)は筋力標準ではなく一般的水準として「目安」明記で参考表示
- 家庭用体組成計の体脂肪率は絶対値精度が低いが、同一計器の継続測定ならトレンドは有効(用途を進捗確認に限定)
