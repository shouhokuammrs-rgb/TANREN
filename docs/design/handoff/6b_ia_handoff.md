### 2-3. 体重チップ(P-3の解)

- 位置: ヘッダー右、期間セグメントの下段(見出しと同じ行の右端に置くと窮屈なため2段構成)
- 静止時: 枠 `#3A2213` 1px・角丸999px・padding `7px 12px`。「体重 70.0kg ✎」Mono 700 12px `#B06A3E`
- 前回更新から**7日以上**経過: 枠 `#FF5C1A`・文字 `#FF7A33`・末尾に「· 7日前」を付す(通知はしない)
- タップ → インライン展開(画面遷移なし):
  - −/+ ステッパー **0.5kg刻み**・範囲 30.0–200.0kg
  - ボタン 36×36 円形(タップ領域44px)・枠 `#3A2213` / hover `#FF5C1A`
  - 値 Anton 28px `#FFE3CC` tabular-nums / 常に小数第1位表示(`70.0`)
  - 「保存」テキストボタン `#FF5C1A`。保存で畳む + Toast「体重を更新しました」
- 保存の副作用: 全部位の目標e1RM(= 係数 × 体重)とゴール進捗を即時再計算。**器具上限帯 33.6kg は不変**
- 設定「①日常」にも同じ体重項目を残す(入口2つ・実体1つ)

### 2-4. セグメント

- 幅いっぱいの2分割。高さ36px・枠 `#241812`・角丸999px・padding 3px
- 選択: 背景 `#FF5C1A`・文字 `#0B0907` Noto 700 12px / 非選択: 文字 `#8A5A3C`
- 既定は「成長」。選択状態はセッション内のみ保持(再訪時は成長に戻す)

### 2-5. 熱の人体図・グラフ

DEC-011 の仕様をそのまま移設。`docs/design/growth_viz_concepts.md` の実装仕様セクションが正:
- 色は常に**月換算の伸び率**でエンコード(6段階閾値表)
- データ不足(表示期間内セッション3回未満)= 冷えた鉄 `#1C140E` + 破線枠
- e1RM推移カードにゴールライン(`#FFE3CC` 実線 + 右端値タグ)と `{進捗率}% ・ あと{残り}kg`

### 3-2. 回復ステータス統合(ISS-016)

フレッシュネス人体図と回復予測スロットを1コンポーネントに統合。**回復予測の独立スロットは廃止**。

**状態A — 回復待ちの部位がある(既定)**

| 要素 | 仕様 |
|---|---|
| コンテナ | 枠 `#3A2213` 1px・角丸14px・padding `16px 18px` |
| ラベル | 「回復ステータス」Mono 500 10px `.28em` `#8A5A3C` |
| 人体図 | FRONT のみ・高さ150px・中央。部位色 = **鈍色スケール**(回復済み `#6B5A4C` / 回復中 `#8A5A3C` / 直近負荷 `#B06A3E`)|
| サマリー行 | 「あと18時間で 胸 が回復」Noto 700 13px `#D9CFC6` — 最も遠い部位を1つだけ出す |

**部位タップ → 吹き出し**
- 人体図の該当部位の上に表示。背景 `#1A110B`・枠 `#3A2213` 1px・角丸8px・padding `8px 10px`
- 内容: 部位名(Noto 700 12px `#D9CFC6`)+「あと18時間」(Mono 700 12px `#B06A3E`)+ 回復バー(幅90px・高さ4px・`#8A5A3C`)
- 回復済みの部位: 「回復済み」`#D9CFC6`(バーは満杯・`#6B5A4C`)
- 外側タップ / 他部位タップで閉じる。同時に開くのは1つ

**状態B — 全部位が回復済み(1行に畳む)**
- 人体図を出さない。高さ48pxの1行に:「全部位 回復済み」Noto 700 14px `#D9CFC6` + 左に 8px ドット `#6B5A4C`
- 枠・角丸は状態Aと同一。タップで人体図を展開できる(任意・実装優先度低)

**色の原則:** 回復は**鈍色のみ**。溶鉄(成長)・鋼色(維持)を使わない。

## 4. 設定3群 `/settings`

### 4-1. 構成

```
① 日常              常時展開・最上段
   ├ 部位別ゴールゲージ(5b・5部位)
   └ 体重(0.5kg刻みステッパー)
② からだと器具      アコーディオン・既定すべて閉
   ├ 器具
   ├ 筋力キャリブレーション
   ├ 怪我・制限
   ├ タイマー
   └ エンジン調整(上級者)
③ データ            常時展開・最下段
   ├ クラウドバックアップ
   ├ エクスポート / インポート
   └ 全データ削除 →/settings/danger(画面遷移)
```

### 4-2. 群ヘッダー

| 要素 | 仕様 |
|---|---|
| 群見出し | Mono 500 10px `.28em` — ①`#FF7A33` / ②`#8A5A3C` / ③`#C9B79C` |
| 補足1行 | Noto 400 10px `#6B5A4C`(①「よく触る操作」②「一度決めたら滅多に触りません」③「保全と削除」)|
| 群間 gap | 28px(群内の項目間は 10px)|

### 4-3. アコーディオン(群②)

| 状態 | 仕様 |
|---|---|
| 閉(既定) | 高さ52px。行 = 項目名(Noto 700 13px `#D9CFC6`)+ 現在値の要約(Mono 500 11px `#8A5A3C`、例「24kgダンベル ×2」)+ シェブロン `#6B5A4C` |
| 開 | シェブロン180°回転(.2s)。中身は既存UIをそのまま。枠 `#3A2213`、背景 `rgba(255,255,255,.015)` |
| 開閉状態 | 保存しない(再訪時は常に全閉)|

一度に開けるのは1項目(他を開くと前を閉じる)。

### 4-4. データ群と全削除の隔離

- 「全データ削除」行: 枠 `#3A2213`・文字 `#B06A3E`・右端に「→」。**この画面では削除しない**
- 遷移先 `/settings/danger`(通常の画面遷移。モーダルではない)

**`/settings/danger` の2段確認**

| 段 | 仕様 |
|---|---|
| 画面 | 見出し「全データを削除」Noto 900 22px `#F5EFE8`。本文で消えるもの(セッション記録・ゴール・写真・体重履歴)を箇条書き。「この操作は取り消せません」`#D9CFC6` |
| 1段目 | 確認テキスト入力: 「削除」と入力させる。入力一致まで実行ボタンは無効 |
| 実行ボタン | 無効時: 枠 `#3A2213`・文字 `#4A3A2C`・背景なし / 有効時: 背景 `#D8321A`・文字 `#FFE3CC` |
| 2段目 | ネイティブアラートで最終確認(「削除する」/「キャンセル」)|
| 直前 | 実行前に自動エクスポートを促す導線を1つ置く(「先にエクスポートする」テキストボタン `#FF7A33`)|

- `#D8321A`(deep-red)を**破壊操作の色として初めて単独使用**する。グラデ終点以外での使用はこの1箇所に限定し、他へ広げない
