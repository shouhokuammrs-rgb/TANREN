## 0. 確定事項

| 項目 | 決定 |
|---|---|
| 配置 | **設定画面のみ**(v1)。初回セットアップウィザードへの組み込みはスコープ外 |
| 対象部位 | 胸・背中・肩・腕・脚 の5部位。尻・腹はUIに出さない |

## 1. データモデル

```
目標e1RM = 体重 × 係数(部位, レベル)    // 片手kg、小数第1位
capped   = 目標e1RM > 33.6
進捗率   = clamp0-100((現在 - スタート) / (目標 - スタート) × 100)
残り     = max(0, 目標 - 現在)
表示     = `{進捗率}% ・ あと{残り}kg`
```

- スタート = その部位のゴール設定時点の e1RM(設定変更時は据え置き。ゴール変更で再設定しない)
- 目標値の直接編集後は `係数 = 目標 ÷ 体重` を逆算保持(体重変更時も比率が追従)

### 係数表(承認済み・研究資料 §3)

| 部位 | 引き締め | しっかり | がっつり |
|---|---|---|---|
| 胸 | 0.35 | 0.50 | 0.70 |
| 背中 | 0.35 | 0.55 | 0.75 |
| 肩 | 0.25 | 0.40 | 0.55 |
| 腕 | 0.15 | 0.30 | 0.50 |
| 脚 | 0.25 | 0.40 | 0.60 |

体重70kg時に capped となるのは: 胸「しっかり」以上 / 背中「しっかり」以上 / 肩・腕・脚「がっつり」。

## 3. ゲージ寸法(1行 = 1部位)

コンテナ: 枠1px・角丸14px・padding 13px 16px・行内 gap 7px。

| 要素 | 寸法・位置 |
|---|---|
| トラック領域 | 高さ 26px(絶対配置の基準) |
| トラック | `top: 11px` / 高さ4px / 角丸2px / `#241812` |
| 進捗フィル | `top: 11px` / 高さ4px / `left: startX` → 幅 `curX - startX` / `linear-gradient(90deg,#8A431C,#FF5C1A)` |
| スタートマーカー | `top: 7px` / 2×12px / `#57503F` |
| 現在地マーカー | `top: 0` / 2×26px / `#FFE3CC` |
| ノッチ(×3) | 18×18円 / `top: 4px` / `margin-left: -9px` / 枠2px |
| 上限帯 | `top: 8px` / 高さ10px / `left: capX` → 右端 / `repeating-linear-gradient(-45deg, #241812 0 3px, transparent 3px 6px)` |

**X座標の正規化**: `maxV = max(がっつり目標, 33.6) × 1.14`、`x = min(97, 値 / maxV × 100)%`。
体重変更時、ノッチ・現在地・スタートは動き、**上限帯だけ 33.6 の位置に留まる**(=これが本UIの主張)。

行内テキスト:
- 1段目: 部位名(Noto 700 13px `#F5EFE8`)/ 右に `{レベル名} {目標}kg`(Mono 700 12px)
- 3段目: 左「現在 {n}kg(白線)」(Mono 500 9px `#6B5A4C`)/ 右 **`{進捗率}% ・ あと{残り}kg`**(Mono 700 12px `#FFE3CC`)
- 4段目: **説明キャプション**(Noto 400 11px/1.5 `#9B928A`・上に `#1A110B` 1px 罫線・padding-top 7px)

### 説明文(生活言語)

| 部位 | 引き締め | しっかり | がっつり |
|---|---|---|---|
| 胸 | Tシャツの胸元にうっすら厚みのラインが出る | Tシャツの上から胸の張りがわかる | シャツ選びで胸囲が基準になる |
| 背中 | 「姿勢が良くなった」と言われる | 後ろ姿で逆三角形の輪郭がわかる | ジャケットの肩幅が既製では合わなくなる |
| 肩 | 肩のラインが丸みを帯びる | 半袖で肩の張り出しがわかる | ノースリーブで三角筋の分離が見える |
| 腕 | 袖から出る腕にうっすら形がある | 半袖で明らかに鍛えているとわかる | 腕まくりで周囲がざわつく |
| 脚 | パンツのシルエットが崩れない程度に締まる | 細身のパンツで太ももの張りがわかる | 既製のパンツが太ももで選べなくなる |

フッター注記(画面に1回):「※ 見え方は体脂肪率や骨格でも変わります」(Noto 400 10px `#6B5A4C`)

## 4. 状態定義(5状態)

| # | 状態 | 発生条件 | 行の枠 / 背景 | ノッチ | 数値・キャプション |
|---|---|---|---|---|---|
| 1 | **未設定** | ゴール未選択 | `#241812` / transparent | 全て枠 `#3A2213`・塗り `#140B06` | 目標欄「未設定」`#6B5A4C`。進捗・説明文は非表示。進捗フィルなし |
| 2 | **選択中** | その行がフォーカス | `#FF5C1A` / `rgba(255,92,26,.06)` | 選択レベルのみ枠+塗り `#FF5C1A` + `0 0 10px rgba(255,92,26,.6)` | ヒーローに連動。レベル名 `#FF7A33` |
| 3 | **capped** | 目標 > 33.6kg | 枠は状態1/2に従う | 選択ノッチは斜線帯の内側に描画(色そのまま=選択は妨げない) | レベル名 `#8A5A3C` に減光。行下に「⚠ 現在の器具では届きません(計測上限 33.6kg)」 |
| 4 | **到達(鏡チェック待ち)** | 現在 ≧ 目標 | 枠 `#FFB300` / `rgba(255,179,0,.07)` | 選択ノッチ `#FFB300` + グロー | 進捗表記を「達成 — 判定待ち」に置換。行タップで鏡チェックへ。`emberPulse 2.4s` |
| 5 | **維持(鋼色)** | 鏡チェックで「満足」 | 枠 `#57503F` / `rgba(201,183,156,.05)` | 選択ノッチ `#C9B79C`・**グローなし** | 目標値・進捗を `#C9B79C`、右端に「✓ 維持」。進捗フィルも `#C9B79C` の単色に |

状態遷移:
```
未設定 ──レベル選択──> 選択中 ──(セッション記録で現在値が目標到達)──> 到達
                                              ├─ 満足     ──> 維持
                                              └─ 物足りない ──> 選択中(1段上のレベル・スタート据え置き)
維持 ──ゴール変更 / 再点火──> 選択中
```

- 到達判定は**セッション保存時**に評価。通知は1回のみ(判定するまで再通知しない)
- 維持モードの部位はメニュー生成側で「週1・現重量」に落とす(実行画面の仕様はスコープ外)

## 5. 成長ビューへのゴールライン統合

- e1RM推移グラフに水平のゴールライン: `#FFE3CC` 1.5px。5bは実線+右端に値タグ(`#FFE3CC` 塗り・角丸3px・Mono 700 10px `#0B0907`)
- カードヘッダー右に `{進捗率}% ・ あと{残り}kg`(Mono 700 12px `#FFE3CC`)
- 人体図・部位カードの色は既存のまま(成長=溶鉄の彩度)。**ゴール達成度で色を変えない** — 維持モードの部位のみ鋼色 `#C9B79C` にフラットに置換し、熱スケールから外す
