# INS: 旧ゴール残骸の後始末(ISS-023昇格)

- 発行: PM / 2026-08-01 / 対象: Engineer / 運用: DEC-014準拠

## 背景
IA再設計で旧ゴールの保存処理を撤去した結果、ホームのセットアップバナー(`goal === null` 判定)が誤発火し、旧ウィザードの「目標ボディ」ステップへ誘導している。部位別ゴール(DEC-013)設定済みユーザーに旧目標を聞く重複が発生(オーナー実害)。

## 仕様
1. ホームのセットアップバナー条件を**muscle_goals基準**に変更: 「部位別ゴールが1件も未設定」の場合のみ表示。文言も新モデルに合わせ「目標を設定すると〜」→部位別ゴールへの導線(設定①へ遷移)に差し替え
2. セットアップウィザードから**目標ボディステップ(goalType/wantParts)と関連分析ページを撤去**。ウィザード末尾に「部位別ゴールは設定からいつでも」の1行案内を置く
3. 旧goalType/wantPartsの読み取り残骸コードを削除(DBレコードは触らない=既存バックアップ互換維持)

## テスト
バナー表示条件(muscle_goalsゼロ件で表示/1件以上で非表示)/ ウィザード完走回帰 / 旧参照削除後のビルド

## 完了条件
handoff+SSOT(ISS-023対応済み)+main push
