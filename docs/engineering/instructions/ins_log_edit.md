# INS: ログの事後編集(ISS-020)

- 発行: PM / 2026-08-01 / 対象: Engineer / 運用: DEC-014準拠

## 背景
記録し忘れ(実際は多くレップをやったのに未修正)を後から直せない。オーナー実害あり。

## 仕様
- LogDetailPageで**セット単位のweight/reps編集+セット追加・削除**を可能にする
  - weightは0.5kg刻みに丸め、reps>0。自重種目はweightなしのままrepsのみ編集可
  - セット削除で種目のセットが0になる場合はその種目記録ごと削除(確認ダイアログ)
- スコープ: 既存セッション内の編集のみ。**種目の追加・セッション日時変更・セッション削除はスコープ外**(必要ならISS)
- 派生値(e1RM・成長ビュー・ゴール進捗・状態4導出)は純関数のため自動反映——再計算コードを足さないこと
- **遡及再判定はしない(v1)**: 編集によって過去のPR演出・goal_events(reached等)は書き換えない。編集で現在e1RMが目標を跨いだ場合、状態4は導出表示なので自然に出現/消滅するが、イベント記録は次のfinishSession判定に委ねる
- 編集したセッションに「編集済み」の控えめな表示(updatedAtで判定)。編集履歴の保持はしない
- クラウドバックアップは既存の変更検知に乗ること(編集がアップロード対象になるか確認)

## テスト
編集・追加・削除・丸め・種目0セット削除・派生値反映(成長点列が編集後値で再計算されること)

## 完了条件
handoff+SSOT(ISS-020対応済み)+main push。迷いはPM確認事項へ

## 追記(2026-08-01・オーナー観察より)

編集の実利用は「トレ直後に記録ミスに気づく」ケースが主。**サマリー画面から当該セッションのログ編集へ直行する導線**(1リンクで可)を仕様に追加する。実装済みの場合は小追加として対応。
