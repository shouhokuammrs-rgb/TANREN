## 2. 腹の加重昇格(DEC-017改)

- 種目マスタ追加「**ダンベルクランチ**」: 腹・isolation・core・dumbbell・**8〜15回**・initialWeightFactor 0.04(→初回2.5kg)・**isActive: 0**(昇格受諾まで選択対象外)。名前突合のマスタ同期(seed.ts)で既存DBにも追加される
- 発火(spec §1-2): サマリー表示時にそのセッションのクランチ完了セットへ共通述語 `isCapReached`(全セット達成×最小レップ≧上限×限界フラグなし=progression.tsの自重頭打ち分岐と同条件)を適用して導出。**クランチのみ**。レッグレイズは提案なし
- 昇格カード(spec §1-3): サマリーの総ボリューム直下・PRカードより上。対比ブロック(いま自重25回×3→次2.5kg・8回から)+受諾/見送り。押下後は確認ブロックに置換(受諾=molten/見送り=steel)・同一サマリー内の取り消しなし
- 受諾 = クランチ`isActive:0`+ダンベルクランチ`isActive:1`(ログはexerciseId参照のため履歴不変・レッグレイズは触らない)。以後は通常のe1RM増量ループ(DEC-007)に自然合流(テストで確認)。見送りは**保存しない**=次に同条件を満たした回に再提案

## 3. 腹の段位型ゴール(DEC-018改)

- **条件クリアは永続保存**(PM裁定§6-4・導出再判定にしない): `goal_events` に `type: 'abs_condition'`+`condition: 'C1'|'C2'|'C3'` を追加(スキーマ変更なし・非インデックス列。バックアップはgoal_eventsテーブル丸ごと保存のため追加作業なし)。セッション保存時(`finishSession`→`recordAbsProgress`)に未クリア条件のみ判定・記録。**一度クリアした条件は落ちない**(加重移行後もC1維持=テスト済み)
- 段位導出(順不同): `absAttained` = C3→がっつり / C1∧C2→しっかり / C1∨C2→引き締め。到達判定=到達段位ランク≧選択段位ランク
- 到達→鏡チェック→維持は既存共通ループ合流: `reachedAt`/`goal_events`/`MirrorCheckModal`/タブ通知/ホームバナー/サマリー到達カードすべて自動で腹に対応。腹の「物足りない」=段位1段上げ(coef 0固定)・**がっつり到達時は引き上げ選択肢を出さない**(kg直接編集は腹に不適用)。維持モードのメニュー縮小(種目1)も既存`goalModes`経由で自動適用
- `saveAbsGoal`: saveMuscleGoal(ISS-019/DEC-016)と同じ規則で保存時再評価——到達済み段位を選び直すと即到達(抑制運転)・未達段位へ変えるとクリア
- 係数経路の隔離(spec §2-5): `MuscleGoal`は`muscle:'abs'`・`coef:0`で流用。`GOAL_COEF`/`GOAL_TARGET_MUSCLES`/`targetE1Rm`不変。`detectReachedGoals`に対象部位ガードを追加し腹がe1RM判定に混入しないことを明示化。優先度は腹=中立1.0のまま
- **AbsGoalRow**(設定①・5部位ゲージ直後): 段位バッジ3つ(gap6px・角丸8px統一・階段状にしない)+条件チェックリスト(充足=steel✓・これが進捗本体)+順不同注記+充足数(「自重 1/2 種目」形式・**「n/3」表記なし・進捗%なし**)+生活言語キャプション。ドラフト・保存CTA・維持→再開確認は5部位と共通

## 4. 体脂肪率+腹詳細2軸(DEC-018 §3/§4)

- 入力: 設定①体重ステッパーカード下段に「体脂肪率(任意)」行(閉=`17.2% ✎`/開=0.1%刻みステッパー・3.0〜60.0)。保存CTAで体重と**1レコードにまとめて**`body_stats`へ(既存`addBodyWeight(weightKg, bodyFatPct?)`利用・スキーマ変更なし・バックアップ既対応)
- 腹詳細(成長タブで腹選択時・汎用推移カードと差し替え): 上「**厚み — 段位**」card-ember(バッジ表示のみ+クランチ系列グラフ+レッグレイズ頭打ち状態行(CTAなし))/下「**薄さ — 体脂肪率トレンド**」弱枠カード(鈍色線・熱スケール不使用)

## PM確認事項(実装で解決せず記載)

1. **ダンベルクランチのレップレンジ=8〜15**(spec §6-1の未確定項): 下限8は仕様§1-3「2.5kg・8回から」に固定。上限15は加重アイソレーションの一般的レンジからEngineer裁量で設定(自重クランチの25のままでは加重の意味が薄れるため)。C3(がっつり)のクリア条件はこの15に依存します。調整はシード値変更のみで可能
2. **条件→種目の対応は種目IDでなく種目名で定義**(`ABS_CONDITIONS`): spec §5は「種目IDで持つ」とあるが、DBのidは自動採番で環境依存のため定数化できず、マスタ同期(seed.ts)も名前突合。名前を安定識別子として採用
3. **チェックリストC2行の表示**: 仕様の「充足済み(steel)」と「頭打ち中(#8A431C枠)」がレッグレイズで重なるため、C2充足時=枠#8A431C+背景steelの統合表現にした
4. **見送り後の再表示**: 見送りは保存しない仕様(毎回再提案)のため、同一サマリーを後日開き直すとカードが再表示される(受諾するまで)。うるさければISSで
5. **ゴール未設定でも条件クリアは記録される**: 後から段位を設定した時点で充足していれば保存時に即到達(鏡チェックへ)。チェックポイント思想に沿う挙動として実装
